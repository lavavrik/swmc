# Security

## Report a vulnerability

Do not open a public issue for a security problem.

To report a vulnerability, use the private form on GitHub:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem and the steps that show it.

Only the maintainer can see the report. You get a reply on the report.

## Scope

The reports that apply are about:

- the editor in the browser
- the cloud library API in `server/`
- the MCP server and the `mc` CLI.

Only the latest release gets security fixes.
