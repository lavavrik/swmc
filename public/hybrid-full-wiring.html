Pipes are universal

RPS / torque and fluid both use the pipe tool. Straight pipes, corners, T-junctions, crosses. A cross can carry RPS and fluid at the same time.

Two RPS pipes: Engine → Engine Gen → Generator (charge). Engine → Starter clutch → Motor → Drive clutch → GB → Wheels. T-off the generator from the engine. If it sits behind the starter clutch, charge dies when that clutch opens at Start RPS.

Clutches and gearboxes pass RPS, not fluid. Fuel/air/exhaust/coolant need their own path around those boxes (or a cross before them).

Electric is still the yellow network. Gearboxes need it to switch. Battery 0..1 on the MCU is a number, not that node.

Logic: Seat data (W/S = ch 2). Physics sensor (abs speed = ch 13). Instruments out: ch 1 engine RPS, ch 2 speed m/s, ch 3 battery, ch 4 gear. Wheel Brakes number to the brake pads; regen takes over as wheel RPS rises.
